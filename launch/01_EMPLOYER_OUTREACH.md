# 01 — ชุดหา Employer (พร้อม copy-paste)

> **ไฟล์นี้ใช้ยังไง:** ก็อปข้อความข้างล่างไปส่ง/อ่านได้เลย ไม่ต้องคิดเอง พี่แค่เติมชื่อร้าน + โซน เลือกแบบที่ชอบ แล้วส่ง LINE/Facebook/เดินเข้าร้าน
> เป้าสัปดาห์ 2: ทัก 20-30 ร้าน → ได้ 2-3 ร้านลองโพสต์งานจริง

---

## 🎯 วิธีหา target 20-30 ร้านในโซน (ใช้เวลา ~1 ชม.)

1. เปิด **Google Maps** พิมพ์ "ร้านอาหาร [ชื่อโซน]" เช่น "ร้านอาหาร อ่อนนุช"
2. กวาดร้านที่ **มีหน้าร้านจริง + ดูคนพลุกพล่าน** (ร้านยุ่ง = ขาดคนบ่อย = ลูกค้าเรา) จดชื่อ + เบอร์/เพจ ลงตาราง
3. เน้นประเภท: ร้านตามสั่ง/อาหารจานด่วน, ร้านชาบู/หมูกระทะ (ใช้เด็กเสิร์ฟเยอะ), คาเฟ่ที่คนแน่น, ร้านในตลาด/ฟู้ดคอร์ท
4. **ช่องทางทักเรียงตามได้ผล:** (1) เดินเข้าร้านช่วงบ่าย 14:00-16:00 ที่ร้านว่าง คุยกับเจ้าของ/ผู้จัดการ (2) ทักเพจ Facebook ร้าน (3) LINE OA ถ้ามี
5. เก็บลงตารางง่ายๆ: `ชื่อร้าน | ช่องทาง | ทักวันไหน | ผลตอบกลับ`

> Tip: ร้านที่ติดป้าย "รับสมัครพนักงาน" หน้าร้าน = กำลัง pain เรื่องคน = ลูกค้าที่ร้อนที่สุด ทักก่อนเลย

## 💬 LINE / Facebook DM Templates

### แบบ A — สั้น ตรง (ใช้ทักเพจครั้งแรก)
```
สวัสดีครับ/ค่ะ ร้าน [ชื่อร้าน] พอดีผมทำแอพ WeHire
ช่วยร้านหาพนักงานรายวัน (เด็กเสิร์ฟ/ครัว/ล้างจาน) เวลาขาดคนกะทันหันครับ

โพสต์งานฟรี เห็นโปรไฟล์+รีวิวคนทำงานก่อนเลือก จ่ายเฉพาะตอนได้คนจริง
ช่วงนี้เปิดให้ร้านแถว [โซน] ลองใช้ฟรีไม่มีค่าใช้จ่ายครับ

ร้านพี่ช่วงไหนขาดคนบ่อยสุดครับ? เดี๋ยวผมช่วยตั้งให้เลย
```

### แบบ B — เน้นแก้ปัญหา (ใช้กับร้านที่เห็นว่าขาดคน)
```
สวัสดีครับ เห็นร้าน [ชื่อร้าน] รับสมัครพนักงานอยู่พอดี
ผมทำแอพ WeHire หาคนทำงานรายวันให้ร้านอาหารแถว [โซน] ครับ

เคสที่ร้านชอบเจอ: เด็กลาออกกะทันหัน เสาร์-อาทิตย์คนไม่พอ
แอพช่วยหาคนมาเสริมเป็นรายวันได้ภายในวันนั้นเลย
มีโปรไฟล์ + รีวิว + ยืนยันตัวตน เลือกได้ก่อนจ้าง

อยากชวนร้านพี่ลองใช้ฟรีช่วงเปิดตัวครับ ขอเบอร์/ไลน์ติดต่อกลับได้ไหมครับ?
```

### แบบ C — อบอุ่น เป็นกันเอง (ใช้ตอนเดินเข้าร้านแล้วขอไลน์ทีหลัง)
```
ขอบคุณที่คุยด้วยนะครับพี่ 🙏
ตามที่คุยกันเรื่องแอพหาคนรายวัน WeHire นี่ลิงก์ครับ
👉 https://wearehiredmvp.vi-nutthaphat.workers.dev

ครั้งแรกผมช่วยตั้งโพสต์ให้เลย พี่แค่บอกผมว่า
อยากได้คนตำแหน่งอะไร วันไหน กี่โมง ค่าแรงเท่าไหร่
เดี๋ยวผมจัดให้ครับ ลองดูสักงานนึงก่อนได้เลย ไม่มีค่าใช้จ่าย
```

## ☎️ สคริปต์คุย/โทรสั้นๆ (อ่านตามได้เลย — สำหรับคนไม่ถนัดคุย)

> หายใจเข้า ยิ้ม แล้วอ่านตามนี้ ไม่ต้น improvise พอเขาตอบค่อยฟังแล้วตอบจากส่วน objection ข้างล่าง

**เปิด (10 วินาที):**
> "สวัสดีครับพี่ รบกวนแป๊บเดียวนะครับ ผมชื่อ[ชื่อ] ทำแอพหาพนักงานรายวันให้ร้านอาหารแถวนี้ครับ ไม่ทราบว่าร้านพี่เคยเจอปัญหาขาดคนกะทันหันไหมครับ?"

**ถ้าเขาบอกเคย/บ่อย:**
> "ใช่เลยครับ อันนี้แหละที่แอพผมช่วย คือเวลาพี่ขาดคน โพสต์ในแอพ แล้วมีคนหางานรายวันแถวนี้มาสมัคร พี่เห็นโปรไฟล์กับรีวิวก่อนเลือก จ่ายเฉพาะตอนได้คนจริงครับ"

**ปิด (ขอ commitment เล็ก):**
> "ช่วงนี้ผมเปิดให้ร้านแถว[โซน]ลองใช้ฟรีครับ ขอผมช่วยตั้งโพสต์งานให้พี่สักงานนึงได้ไหมครับ? พี่แค่บอกผมว่าอยากได้คนวันไหน ตำแหน่งอะไร ที่เหลือผมจัดให้"

> หลักการ: ขอแค่ "ลองโพสต์ 1 งาน" ไม่ใช่ "สมัครใช้ถาวร" — friction ต่ำ ปิดง่าย

## 🛡️ Objection Handling (เจอบ่อย ตอบสั้นๆ)

| เขาพูดว่า | ตอบว่า |
|-----------|--------|
| "มีคนของร้านอยู่แล้ว" | "ดีเลยครับ อันนี้ไว้ใช้ตอนคนไม่พอ/ลาออกกะทันหันครับ เก็บไว้เป็นตัวสำรอง ไม่เสียอะไร" |
| "เสียค่าใช้จ่ายเท่าไหร่" | "ช่วงเปิดตัวฟรีครับ ปกติคิดแค่ 6% ตอน match สำเร็จ ไม่ได้คนไม่เสียเงิน" |
| "กลัวได้คนไม่ดี/หนีงาน" | "เข้าใจครับ แอพมีรีวิว + ยืนยันตัวตน + ระบบเช็คอิน GPS ที่หน้างาน ถ้าคนไม่มาเรามีระบบหาคนสำรองให้ทันทีครับ" |
| "ยุ่ง ไม่มีเวลาเรียนรู้แอพ" | "ครั้งแรกผมตั้งให้เลยครับ พี่แค่บอกผมว่าอยากได้อะไร ไม่ต้องกดเอง" |
| "ขอคิดดูก่อน" | "ได้ครับ ผมส่งลิงก์ไว้ให้นะครับ ไว้พี่ขาดคนเมื่อไหร่ทักผมได้เลย ช่วยหาให้ภายในวันนั้น" (แล้วเก็บไลน์ไว้ follow up) |
| "คนหางานรายวันเชื่อถือได้เหรอ" | "เราคัดด้วยรีวิวจากร้านอื่น + มีระบบยืนยันตัวตน คนที่ทำดีจะได้คะแนนสูง พี่เลือกเฉพาะคนรีวิวดีได้ครับ" |

## 📋 Checklist หลังได้ employer รายแรกๆ
- [ ] ช่วยเขาโพสต์งานแรกด้วยมือ (อย่าปล่อยให้งง)
- [ ] เช็คว่ามี worker ในโซนพอจะ match (ถ้ายังไม่พอ → กลับไปไฟล์ 02 หา worker เพิ่มก่อน)
- [ ] อยู่ดูจน loop จบ (เช็คอิน → จบงาน → จ่าย/รีวิว)
- [ ] ขอ feedback ทันที + จดลง metrics tracker
- [ ] นัดล่วงหน้า: "งานรอบหน้าโพสต์อีกนะครับ" → ดัน repeat
