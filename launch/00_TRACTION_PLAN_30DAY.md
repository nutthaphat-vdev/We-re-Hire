# 00 — แผน Traction 30 วัน (Beachhead Plan)

> **ไฟล์นี้ใช้ยังไง:** อ่านอันนี้ก่อนเพื่อน เป็นแผนแม่บท 30 วัน บอกว่าพี่ต้องโฟกัส "โซนเดียว หมวดเดียว" แล้วไล่ทำตามสัปดาห์ ไฟล์ 01–05 คือเครื่องมือลงมือทำในแต่ละ step
> เป้าจริงคือ: คนแปลกหน้าทำ transaction จริง + กลับมาซ้ำ ไม่ใช่ยอด signup สวยๆ

---

## 🎯 หลักคิด: แคบ + หนาแน่น (ห้ามกว้าง)

พี่มี user จริง ~0 ตอนนี้ปัญหาไม่ใช่ "คนน้อย" แต่คือ **liquidity** — ต้องมี worker พอที่ employer โพสต์แล้วมีคนมาจริง และมี employer พอที่ worker เปิดแอพแล้วเจองาน ถ้ากระจายทั่ว กทม. = บางทุกจุด = ไม่มี match = ตายเงียบ

วิธีแก้: **บีบให้แน่นในพื้นที่เล็กๆ ก่อน** ทำ "ตลาดจิ๋วที่ทำงานได้จริง" 1 จุด แล้วค่อยขยาย นี่คือ do-things-that-dont-scale พี่ทำมือทุก match ใน 30 วันแรกได้เลย

---

## 📍 เลือก Beachhead: โซน + หมวดงาน

### หมวดงานที่ควรเริ่ม → **ร้านอาหาร / F&B (ครัว, ล้างจาน, เสิร์ฟ, เด็กร้าน)**

เหตุผล:
- **Demand ถี่และด่วน** — ร้านอาหารขาดคนเป็นรายวันจริงๆ (คนลาออกกะทันหัน, เสาร์-อาทิตย์ลูกค้าแน่น) = pain เฉียบพลัน = ยอมลองของใหม่
- **Supply หาง่าย** — งานครัว/เสิร์ฟ ไม่ต้องมีทักษะสูง คนหางานรายวันเยอะ เทรนหน้างานได้
- **รอบสั้น เห็นผลไว** — โพสต์เช้า ทำงานเย็น จบใน 1 วัน = เก็บ completed job ได้เร็ว = data มาไว
- **ความเสี่ยงต่ำ** — งานไม่ต้อง NDID/work permit ตอนนี้ (เก็บ moat นั้นไว้ขาย employer ทีหลัง)

> ทางเลือกสำรอง: **คลังสินค้า/โกดัง (warehouse, แพ็คของ)** ในย่านบางนา/ลาดกระบัง demand เป็น batch ใหญ่ (จ้างทีละ 5-10 คน) ดีถ้าพี่อยากดัน GMV เร็ว แต่หา employer ยากกว่า F&B เริ่มที่ F&B ก่อน ถ้า 2 สัปดาห์แรกฝั่ง employer ติด ค่อยสลับ

### โซนที่ควรเริ่ม → **เลือก 1 ย่านที่ "พี่ไปถึงได้ด้วยตัวเอง"**

เกณฑ์เลือกโซน (เรียงความสำคัญ):
1. **พี่เดินทางไปได้สะดวก** — เพราะ 30 วันแรกต้องเดินเข้าร้านจริง ถ่ายรูป ช่วย onboard มือ
2. ร้านอาหารหนาแน่น เดินถึงกันได้ในรัศมี 2-3 กม.
3. มีหอพัก/คอนโดคนทำงานรายวันอยู่ใกล้ = worker supply

ตัวเลือกที่ดี (เลือก **1 เดียว**): **อ่อนนุช–อุดมสุข**, **รัชดา–ห้วยขวาง**, **ลาดพร้าว**, **บางกะปิ**, หรือย่านที่บ้าน/ที่ทำงานพี่อยู่ใกล้สุด

> **กฎเหล็ก:** 30 วันแรก match เกิดเฉพาะในโซนนี้ อย่ารับ employer นอกโซนแม้เขาจะสนใจ (บอกว่า "กำลังขยายไป จะติดต่อกลับ") — กระจายตอนนี้ = ฆ่า liquidity

---

## 📊 เป้าตัวเลข 30 วัน

| Metric | เป้า 30 วัน | ทำไมสำคัญ |
|--------|------------|-----------|
| Completed jobs (จบ loop จริง จ่าย/รีวิว) | **~20 งาน** | ตัวเลข traction หลักที่ angel ดู |
| Active employers (จ้างจริง ≥1 ครั้ง) | **~5 ร้าน** | พิสูจน์ demand |
| **Repeat employers** (จ้างซ้ำ ≥2 ครั้ง) | **2-3 ร้าน** | ⭐ ตัวเลขสำคัญสุด = product-market fit signal |
| Active workers (ทำงานจริง ≥1 ครั้ง) | **15-20 คน** | พิสูจน์ supply |
| Fill rate (งานที่โพสต์ → มีคนทำจริง) | **≥70%** | พิสูจน์ว่า marketplace ทำงาน |
| GMV รวม | **฿8,000–15,000** | (20 งาน × ~400-600 บาท) |

> ตัวเลขดูเล็ก — **ตั้งใจให้เล็ก** angel pre-seed ไม่ได้ดูขนาด เขาดู "loop ทำงานจริงไหม + คนกลับมาซ้ำไหม" 20 งานที่มี repeat 3 ราย น่าเชื่อกว่า signup 500 คนที่ไม่มีใครทำ transaction

## 🗓️ ลำดับงานรายสัปดาห์

### สัปดาห์ 0 (2-3 วันก่อนเริ่ม) — เตรียมของให้พร้อม
- [ ] ทำ **QA loop เต็มบนมือถือจริง** ตามไฟล์ `04_QA_CHECKLIST.md` (ห้ามข้าม! ปล่อย user เจอบั๊ก = เสีย first impression ที่ขอคืนไม่ได้)
- [ ] เลือกโซน + ยืนยันหมวด F&B
- [ ] เตรียม list ร้านเป้าหมาย 20-30 ร้านในโซน (ไฟล์ `01`)
- [ ] เตรียม account ทดสอบ + ลบ data ทดสอบออกก่อนเปิดจริง

### สัปดาห์ 1 — สร้าง Supply ก่อน (ไก่กับไข่: เริ่มที่ไข่/worker)
> เริ่มหา worker ก่อน เพราะ employer ที่โพสต์แล้วไม่มีคนสมัคร = หนีไปเลย แต่ worker ที่ยังไม่มีงาน = รอได้
- [ ] โพสต์หา worker ตามไฟล์ `02` ลง FB group หางานรายวัน เป้า **15-20 คนสมัคร** ในโซน
- [ ] ตอบแชท onboard worker มือ ช่วยตั้งโปรไฟล์ให้เสร็จ (do things that don't scale)
- [ ] ปิดท้ายสัปดาห์: มี worker pool พร้อมในโซน ≥15 คน

### สัปดาห์ 2 — เปิด Demand + match แรก
- [ ] เดินเข้า/ทัก employer 20-30 ร้านตามไฟล์ `01` เป้าได้ **2-3 ร้านลองโพสต์งานจริง**
- [ ] **อยู่ข้างๆ ทุก match แรก** — พี่ช่วย employer โพสต์, ช่วย worker เช็คอิน, แก้ปัญหาสด
- [ ] เป้า: **completed jobs 3-5 งานแรก** + เก็บ feedback ทั้ง 2 ฝั่งทันที
- [ ] บันทึกทุกตัวเลขลง `03_METRICS_TRACKER`

### สัปดาห์ 3 — ดัน Repeat + อุด leak
- [ ] ตามไปหา employer ที่จ้างไปแล้ว ชวนโพสต์ "งานรอบหน้า" — **ดัน repeat ให้ได้ 2 ราย**
- [ ] ถาม worker ที่ทำจบแล้วว่าติดอะไร อยากได้งานแบบไหนอีก
- [ ] หา employer ใหม่เพิ่มอีก 2-3 ร้าน
- [ ] เป้าสะสม: completed ~12 งาน, repeat ≥2

### สัปดาห์ 4 — เร่งให้ถึงเป้า + เก็บ story
- [ ] ดันให้ครบ **~20 completed, ~5 employer, repeat 2-3**
- [ ] เก็บ **2-3 quote จริง** จาก employer/worker ("หาคนได้ใน X ชม.", "ได้งานวันรุ่งขึ้น") → ใส่ one-pager
- [ ] เก็บสกรีนช็อต dashboard ตัวเลขจริง
- [ ] อัปเดต `05_ANGEL_ONEPAGER` ด้วยตัวเลขจริง → พร้อมส่ง angel/incubator

## ✅ เกณฑ์ "พร้อม pitch" หลัง 30 วัน
ถ้าได้ครบนี้ = มี story เล่าให้ angel ฟังได้แบบไม่เขิน:
- มี **repeat employer ≥2** (พิสูจน์ว่าไม่ใช่ของเล่นครั้งเดียว)
- Fill rate ≥70% ในโซน
- มี quote จริงจากผู้ใช้แปลกหน้า (ไม่ใช่เพื่อน)
- เล่า unit economics ได้: ต่องาน fee 6% margin ~90%

ถ้ายังไม่ถึง — **ยืดอีก 2-4 สัปดาห์ในโซนเดิม** อย่าเพิ่งขยาย อย่าเพิ่ง pitch ตัวเลขปลอม

---

## ⚠️ กับดักที่ต้องเลี่ยง
- **อย่าขยายโซน/หมวดเร็วเกิน** — บางทุกจุด = ตาย
- **อย่าวัด vanity metric** (signup, page view) — วัด completed + repeat เท่านั้น
- **อย่ายิงแอด** ตอนนี้ — organic + เดินเข้าหามือ ถูกกว่าและได้ feedback ลึกกว่า
- **อย่ากลัวทำงานแบบไม่ scale** — 30 วันนี้พี่คือ "ops คน" match ด้วยมือได้เลย
