# 📞 Checklist โทรถาม HR โรงแรม — เก็บเลขค่า agent

> เปิดไฟล์นี้ค้างไว้ตอนโทร · จดคำตอบลงในช่องว่างเลย
> **เป้าหมายของสายนี้: เอา 3 ตัวเลขกลับมา ไม่ใช่ขายของ**
> โทรวันที่ ______ · คุยกับ ______________ · โรงแรม ______________

---

## ⚠️ อ่านก่อนกดโทร — 30 วินาที

**1. ถามสิ่งที่เขา *เคยทำ* ไม่ใช่สิ่งที่เขา *จะทำ***

| ✅ ถามแบบนี้ | ❌ ห้ามถามแบบนี้ |
|---|---|
| "ครั้งล่าสุดที่เรียก agent จ่ายหัวละเท่าไหร่" | "ถ้าเราคิดถูกกว่า agent จะใช้ไหม" |
| "เดือนที่แล้วเรียกกี่ครั้ง" | "คิดว่าจะใช้บ่อยไหม" |

คนสนิทจะตอบให้เราดีใจ · **ข้อมูลอดีตโกหกยาก ความตั้งใจอนาคตโกหกง่าย**

**2. อย่า pitch ในสายนี้** ถ้าเขาถามว่าของเราเป็นไง ตอบสั้นๆ แล้ววกกลับมาถาม
> *"เดี๋ยวขอเล่าให้ฟังเต็มๆ ทีหลังครับ ตอนนี้อยากเข้าใจของเดิมที่พี่ใช้อยู่ก่อน จะได้ทำให้มันใช้ได้จริง"*

**3. อย่าใส่ตัวเลขนำ** อย่าถามว่า "หัวละ 700 ใช่ไหม" — เขาจะพยักหน้าตาม
ถามปลายเปิด แล้วเงียบรอ

**4. ถ้าเขาไม่สะดวกบอกตัวเลข** อย่าดัน · ถามเป็นช่วงแทน:
> *"ประมาณหลักร้อยต้นๆ หรือเกินห้าร้อยครับ"*

---

## 🔴 3 ตัวเลขที่ต้องได้ (ถ้าได้แค่นี้ก็ถือว่าสายนี้สำเร็จ)

### 1. โรงแรมจ่าย agent หัวละเท่าไหร่ ต่อคน ต่อวัน
> *"ปกติที่เรียก agent มาเสิร์ฟรายวัน โรงแรมจ่ายเขาหัวละเท่าไหร่ต่อวันครับ"*

**คำตอบ:** ______________________________

ถามต่อถ้าตอบคลุมเครือ:
- เป็นราคาต่อหัว หรือเหมาเป็นก้อนต่องาน? ______________
- รวมอะไรบ้าง (ค่าแรง + ค่าบริการ + VAT)? ______________
- จ่าย agent แล้ว agent ไปจ่ายคนงานเอง ใช่ไหม? ______________

> 💡 **นี่คือตัวเลขสำคัญที่สุดในทั้งโปรเจกต์** — ส่วนต่างระหว่างเลขนี้กับที่คนงานได้รับ = มูลค่าทั้งหมดของ WeHire

---

### 2. ปกติเรียกทีละกี่คน · บ่อยแค่ไหน
> *"ปกติเรียกทีนึงกี่คนครับ แล้วเดือนนึงประมาณกี่ครั้ง"*

**จำนวนคน/ครั้ง:** __________ **ความถี่:** __________/เดือน

- ช่วงไหนที่ต้องการเยอะสุด (งานเลี้ยง / High season / สุดสัปดาห์)? ______________
- ตำแหน่งไหนเรียกบ่อยสุด (เสิร์ฟ / แม่บ้าน / ล้างจาน / banquet)? ______________

> 💡 ถ้าตอบ **"2-3 คน"** → bulk hire ไม่สำคัญ
> ถ้าตอบ **"10-15 คน"** → bulk hire คือสิ่งที่ต้องทำก่อนอย่างอื่น

---

### 3. จองล่วงหน้ากี่วัน
> *"ปกติต้องบอก agent ล่วงหน้ากี่วันครับ ถ้าด่วนสุดคือเท่าไหร่"*

**ปกติ:** __________ วัน **ด่วนสุดที่เคย:** __________

> 💡 ถ้าเป็น **"บอกวันนี้เอาพรุ่งนี้"** → ต้องมี worker พร้อมในระบบอยู่แล้ว รอคนสมัครไม่ทัน

---

## 🟡 ถ้ายังคุยต่อได้ (ถามเท่าที่บรรยากาศเอื้อ)

### 4. ทำไมถึงอยากตัด agent ออก
> *"ที่พี่บอกว่าถ้ามีแพลตฟอร์มจะได้ตัด agent ออก — ติดอะไรกับเขาเป็นพิเศษไหมครับ"*

**คำตอบ:** ______________________________

☐ แพง ☐ พึ่งเจ้าเดียวไม่ได้ ☐ คนไม่มีคุณภาพ ☐ ช้า/ไม่ยืดหยุ่น ☐ อื่นๆ ______

> 💡 **คำตอบข้อนี้ตัดสินว่า pitch หลักของเราคืออะไร** — ราคา หรือความเร็ว หรือความไม่ต้องพึ่งใคร

### 5. agent ทำอะไรให้บ้างที่ถ้าหายไปจะลำบาก
> *"ถ้าไม่มี agent แล้ว งานส่วนไหนจะตกมาที่พี่ครับ"*

**คำตอบ:** ______________________________

> 💡 นี่คือรายการสิ่งที่ WeHire **ต้องทำแทนให้ได้** ไม่งั้นถูกกว่าก็ไม่มีใครย้าย

### 6. เคยมีปัญหาอะไรบ้าง — เล่าเคสจริงล่าสุด
> *"ครั้งล่าสุดที่มีปัญหากับแรงงานรายวัน เกิดอะไรขึ้นครับ"*

**คำตอบ:** ______________________________

☐ คนไม่มา ☐ มาสาย ☐ ทำงานไม่ได้เรื่อง ☐ เรียกไม่ทัน ☐ เอกสาร/จ่ายเงิน

### 7. ใครเป็นคนตัดสินใจเรื่องเปลี่ยนเจ้า
> *"ถ้าจะเปลี่ยนวิธีหาคน ต้องผ่านใครบ้างครับ"*

**คำตอบ:** ______________________________

### 8. คนงานได้รับเท่าไหร่ (ถ้าเขารู้)
> *"พี่พอทราบไหมครับว่า agent จ่ายคนงานเท่าไหร่"*

**คำตอบ:** ______________________________

> 💡 ถ้าเขาไม่รู้ = ปกติ · ไปเก็บจากฝั่งคนงานตอนไปยืนกะแรกแทน

## 📊 หลังวางสาย — กรอกทันทีก่อนลืม

```
โรงแรมจ่าย agent : ________ บาท/คน/วัน
คนงานได้รับ      : ________ บาท/คน/วัน  (ถ้ารู้)
ส่วนต่าง         : ________ บาท  =  ______%

WeHire 6% ของ ________ = ________ บาท
โรงแรมจะประหยัด        = ________ บาท/คน/วัน
คนงานจะได้เพิ่ม        = ________ บาท/คน/วัน
```

**ตัดสินจากตัวเลข:**

| ถ้าส่วนต่าง | แปลว่า |
|---|---|
| **> 15%** | 🟢 cost คือ wedge · ใส่ตารางนี้ลง one-pager ได้เลย |
| **8-15%** | 🟡 cost ช่วยได้แต่ไม่พอ · ต้องมี wedge อื่นคู่ (ความเร็ว / batch) |
| **< 8%** | 🔴 **cost ไม่ใช่ wedge** · ต้องเปลี่ยนไป pitch เรื่อง batch fulfillment + ไม่ต้องพึ่ง agent เจ้าเดียว |

**สิ่งที่ต้องทำต่อ ขึ้นกับข้อ 2:**
- เรียกทีละ ≥ 10 คน → ทำ **bulk hire** ก่อนอย่างอื่น
- เรียกทีละ 2-3 คน → ข้าม bulk hire ไปทำ activation ต่อ

## 🚫 อย่าเผลอทำ

- ❌ อย่าสัญญาวันเปิดใช้ / ราคาพิเศษ ในสายนี้
- ❌ อย่าเถียงถ้าเขาบอกว่า agent ดีอยู่แล้ว — **จดไว้ นั่นคือข้อมูล**
- ❌ อย่าถามว่า "จะลองใช้ไหม" — ยังไม่ถึงเวลา และคำตอบจะเป็นการเกรงใจ
- ✅ ปิดสายด้วย: *"ขอบคุณมากครับ พอผมทำเสร็จจะเอามาให้พี่ดูก่อนใครเลย"*
