# 02 — ชุดหา Worker (พร้อมโพสต์)

> **ไฟล์นี้ใช้ยังไง:** ก็อปโพสต์ข้างล่างไปลงกลุ่ม Facebook หางานรายวัน + ช่องทางฟรีอื่นๆ เป้าสัปดาห์ 1 = ได้ worker 15-20 คนในโซนที่เลือก
> หา worker **ก่อน** employer เสมอ เพราะ employer ที่โพสต์แล้วไม่มีคนสมัคร = หนีหายถาวร

---

## 🎯 หลักการ: หาคนในโซนเดียว
อย่าหาทั่ว กทม. โพสต์ระบุโซนชัดๆ ("แถวอ่อนนุช-อุดมสุข") เพื่อให้คนที่อยู่ใกล้ employer มาสมัคร = match ได้จริง = distance score ดี

## 📍 ช่องทาง Organic ฟรี (เรียงตามคุ้มแรง)

**1. Facebook Groups หางานรายวัน** (ช่องหลัก — แรงสุด)
ค้นคำพวกนี้ใน Facebook แล้วขอเข้ากลุ่ม โพสต์ 1-2 กลุ่ม/วัน (อย่าสแปม):
- "หางานรายวัน กรุงเทพ"
- "งานรายวัน Part time กทม."
- "หางานพาร์ทไทม์ [โซน]"
- "งานร้านอาหาร หาคน/หางาน"
- "คนหางาน-งานหาคน [โซน/เขต]"
- กลุ่มประจำเขต เช่น "คนรักอ่อนนุช", "ชาวห้วยขวาง" (โพสต์แนวเพื่อนบ้านช่วยกระจาย)

> มารยาทกลุ่ม: อ่านกฎกลุ่มก่อน บางกลุ่มให้โพสต์เฉพาะวัน/ต้องใส่ #หาคน อย่าโดนแบนเพราะสแปม

**2. ติดประกาศจริง (offline — ได้ worker ตรงโซนสุด)**
- ติดใบปลิว/QR code ที่: หอพักคนทำงาน, ร้านสะดวกซื้อ, ป้ายรถเมล์, ตลาดสด, วินมอเตอร์ไซค์ในโซน
- QR ชี้ไปหน้าสมัคร + เบอร์ไลน์พี่

**3. TikTok / Reels สั้นๆ**
- คลิป 15-30 วิ "หางานรายวันแถว[โซน]? เปิดแอพนี้" ติด #หางานรายวัน #งานพาร์ทไทม์ #หางานกรุงเทพ
- ไม่ต้องสวย เอาชัด เอาจริง

**4. ปากต่อปาก / วินมอไซค์–ป้าขายของ**
- คนกลุ่มนี้รู้จักคนหางานเยอะ ฝากบอกต่อ + ให้ referral

## 📋 Checklist Onboard worker (ทำมือช่วง 30 วันแรก)
- [ ] ใครคอมเมนต์ "สนใจ" → ทักหลังไมค์ภายในวันนั้น (ยิ่งเร็วยิ่งดี)
- [ ] ช่วยเขาตั้งโปรไฟล์ให้ครบ: ทักษะ, โซน/location, ค่าแรงที่รับได้
- [ ] บอกให้เปิด location/GPS (จำเป็นตอนเช็คอิน)
- [ ] เก็บเบอร์/ไลน์ไว้ ส่งงานที่ match ให้ตรงๆ ช่วงแรก (do things that don't scale)
- [ ] โฟกัสคุณภาพ: worker 15 คนที่พร้อมทำจริง > 100 คนที่สมัครแล้วหาย
