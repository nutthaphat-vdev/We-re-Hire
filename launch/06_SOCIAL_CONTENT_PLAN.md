## 1. ทำไมต้องมี FB Page (ต่างจากโพสต์กลุ่มยังไง)

โพสต์กลุ่ม (ไฟล์ 02) = **ยิงแล้วหาย** ดึง reach ได้แต่ไม่มีบ้าน · Page เติม 3 อย่างที่กลุ่มให้ไม่ได้:

1. **Trust / ความน่าเชื่อ** — HR โรงแรม (คนที่พ่อพาเข้านัด) จะ Google + ส่อง Page ก่อนตัดสินใจ · Page ที่มี about ชัด + โพสต์สม่ำเสมอ + รีวิวจริง = "ของจริง ไม่ใช่มิจ" → ปิดดีลง่ายขึ้น
2. **Hub ปลายทาง** — ทุกโพสต์กลุ่ม / ใบปลิว / QR ชี้มาที่ Page → คนลังเลได้ดูของก่อนโหลด → conversion ดีกว่าชี้เข้าแอปตรงๆ
3. **Owned audience** — คน follow = ยิงงานใหม่ให้เห็นซ้ำได้ฟรี (กลุ่มทำไม่ได้ อัลกอไม่โชว์ให้คนเดิม)

## 6. Milestone Ladder + Stage Triggers (spine เดียวของทั้งเกม)

> **นิยาม traction:** 1 traction = **โรงแรม 1 โรงที่ repeat** (repeat กี่ครั้งก็นับ 1) · 20 traction = 20 โรงต่างกันที่ repeat — กัน concentration ในตัว

```
โรงแรมในมือเท่านั้น (ไม่แตะตลาดอื่น)
   ↓ seed worker ด้วยมือ + LINE + social ดึง supply
โรงแรม repeat โรงแรก  ─ พิสูจน์ wedge เวิร์ก
   ↓ เร่ง (นับโรงที่ต่างกัน ไม่ใช่ pair ลึกเจ้าเดียว)
5–8 โรง repeat  ═══  MINIMUM-PITCHABLE → เริ่มเดินคุย Angel ได้
   ↓
20–30 โรง repeat  ═══  TRACTION แข็ง (breadth + retention)
   ↓ ระดมทุน / belt แน่น
ขยายตลาดอื่น (เกม B: TikTok/viral, หมวด/โซนใหม่)
```

**Gate 1 — พร้อม Pitch:**
- **5–8 โรงแรม repeat = minimum-pitchable** (เปิดวง Angel/pre-seed ได้) · **20–30 โรง = traction แข็ง**
- แต่เลขโรงอย่างเดียวไม่พอ — ต้องมาคู่กับ **velocity (กี่โรง/เดือน) + unit econ (fee 6% เก็บจริง, GMV/โรง) + wedge story (ทำไม repeat)**
- → material pitch: **กราฟจำนวนโรง repeat โต/เดือน + repeat frequency** (สำคัญกว่าเลขดิบ)

**Gate 2 — พร้อมขยายตลาด (คนละ gate — อย่าสับสน):**
- belt แน่น + repeat **หลายเจ้า** + (ระดมทุนแล้ว/หรือมั่นใจ demand)
- → ปลดเกม B: TikTok/Reels หว่าน, referral แบบมีรางวัล, เปิดหมวด/โซนใหม่ (รัน `018_job_categories_v2.sql` ทีละหมวดตาม supply)

> ⚠️ **repeat ไม่กี่เจ้า = เขียวให้เร่ง social ดึง worker ใน belt + เริ่ม pitch · แต่ยังไม่ใช่ใบเบิกทางขยายตลาดใหม่** (นั่นคือ Gate 2)
> ก่อนถึง Gate 2: **ถ่ายคลิปเก็บ stock ได้** (worker win, behind-the-scenes) แต่ **ยังไม่ทุ่มยิง TikTok** — ไว้ปล่อยตอน B
