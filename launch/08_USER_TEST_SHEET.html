กฎ 4 ข้อ — อ่านก่อนเริ่ม
  1. ตอนผู้ทดสอบติด ให้เงียบ นับ 1–30 ในใจก่อนพูด — ช่วงเงียบคือข้อมูล ไม่ใช่ความล้มเหลว
  2. อย่าถาม “เข้าใจไหม” → ให้ถาม “ตอนนี้คิดว่าต้องทำอะไรต่อ”
  3. จดสิ่งที่ผู้ทดสอบทำ ไม่ใช่สิ่งที่ผู้ทดสอบพูด — แตะตรงที่ไม่ใช่ปุ่ม / เลื่อนหาของ / กดซ้ำเพราะไม่แน่ใจ
  4. ห้ามอธิบายว่า “จริงๆ มันต้อง…” — ถ้าต้องอธิบาย แปลว่าดีไซน์แพ้แล้ว จบตรงนั้น จดไว้

1สมัครสมาชิก

1.1 เปิดแอปครั้งแรก — ผู้ทดสอบทำอะไรเป็นอย่างแรก
กดสมัครเลย อ่านก่อน ถามว่าทำอะไร ติด
1.2 เลือกสมัครแบบไหน
Google กรอกอีเมล+รหัสผ่าน ลังเลนาน
ถ้าเลือกกรอกเอง — ติดตรงไหน? รหัสผ่าน? อีเมล? เบอร์โทร?
เวลาที่ใช้ทั้งขั้นตอนสมัคร นาที
1.3 เลือกบทบาท (คนหางาน / ผู้ว่าจ้าง) — เข้าใจไหมว่าต้องเลือกอันไหน
เลือกถูกทันที ลังเล เลือกผิด

2หน้าแรก + การ์ด “ตั้งค่าบัญชี”

2.1 เข้ามาหน้าแรกครั้งแรก — ผู้ทดสอบรู้ไหมว่าต้องทำอะไรต่อ
นี่คือปัญหาหลักที่คนทดสอบคนก่อนบอกว่า “ไม่รู้จะไปไหนเริ่มยังไง”
รู้ทันที งง 5–30 วิ งงเกิน 30 วิ ต้องช่วย
2.2 การ์ด “ตั้งค่าบัญชีของคุณ 0/3” — ผู้ทดสอบสังเกตเห็นไหม แล้วรู้ไหมว่ากดได้
เห็น+กดเอง เห็นแต่ไม่กด ไม่เห็นเลย
ถ้าเห็นแต่ไม่กด — ถามว่า “อันนี้คืออะไรครับ” แล้วจดคำตอบดิบๆ
2.3 ผู้ทดสอบเข้าใจ “0/3” ไหม
เข้าใจ ไม่เข้าใจ ไม่สังเกต

3หน้า “หางานใกล้บ้าน” — แผนที่ สำคัญที่สุด

คำถามที่ค้างอยู่: คนที่ไม่คุ้นเทคหางานเจอจากหน้าแผนที่ไหม หรือควรเป็นการ์ดเรียงกันแบบ Shopee
3.1 เปิดหน้านี้ครั้งแรก — ผู้ทดสอบมองไปที่ตรงไหนก่อน
สังเกตสายตา/นิ้ว ไม่ต้องถาม
แผนที่ การ์ดงานด้านซ้าย แถบรัศมี ไม่รู้จะมองตรงไหน
3.2 ผู้ทดสอบรู้ไหมว่า “งาน” อยู่ตรงไหนของหน้าจอ
รู้ทันที หาสักพัก หาไม่เจอ
ใช้เวลาหาจนเจอ วินาที
3.3 ผู้ทดสอบลองแตะหมุดบนแผนที่ไหม
แตะ ไม่แตะเลย แตะแล้วงงว่าเกิดอะไรขึ้น
ถ้าไม่แตะเลย = แผนที่อาจไม่ได้ทำหน้าที่อะไรกับผู้ใช้กลุ่มนี้
3.4 ถามหลังผู้ทดสอบดูสัก 1 นาที: “ถ้าจะสมัครงานสักงาน ต้องทำยังไงครับ”
จดคำตอบเป็นคำพูดของผู้ทดสอบเป๊ะๆ อย่าเรียบเรียง
3.5 ผู้ทดสอบเลื่อนแถบ “รัศมีการค้นหา” ไหม / เข้าใจไหมว่ามันคืออะไร
เลื่อนเอง ไม่แตะ ถามว่าคืออะไร
3.6 GPS — ตอนเบราว์เซอร์ขออนุญาตตำแหน่ง ผู้ทดสอบทำยังไง
กดอนุญาตทันที ลังเลแล้วอนุญาต กดไม่อนุญาต ไม่ขึ้น
ถ้าลังเล — ถามว่าลังเลเพราะอะไร แล้วจดไว้ (ใช้ตัดสินเรื่องเก็บพิกัดต่อ)
3.7 คำถามชี้ขาด — ถามตอนจบหน้านี้: “ถ้าไม่มีแผนที่ มีแต่รายการงานเรียงลงมา จะหาง่ายขึ้นหรือยากขึ้น”
อย่าถามก่อนผู้ทดสอบลองเอง · อย่าบอกว่าอันไหนดีกว่า
ง่ายขึ้น ยากขึ้น เหมือนกัน ตอบไม่ได้

4โปรไฟล์ + เลือกตำแหน่งงาน

4.1 หมวดงาน → ตำแหน่งงาน (2 ช่องต่อกัน) — ผู้ทดสอบเข้าใจว่าต้องเลือกหมวดก่อนไหม
เข้าใจเอง กดตำแหน่งก่อนแล้วงงว่าว่างเปล่า ต้องช่วย
4.2 ผู้ทดสอบรู้ไหมว่าเลือกได้มากกว่า 1 ตำแหน่ง (สูงสุด 3)
ลองเลือกเพิ่มเอง เลือกอันเดียวแล้วไปต่อ ถาม
ถ้าเลือกอันเดียวแล้วไปต่อ — ทีหลังค่อยถามว่า “ผู้ทดสอบทำงานอะไรได้บ้าง” ถ้าตอบได้หลายอย่าง = UI ยังสื่อไม่พอ
4.3 ปุ่ม × สีแดงบนป้ายตำแหน่ง — ผู้ทดสอบเห็นไหม / รู้ไหมว่าเอาไว้ลบ
เห็นและใช้ถูก เห็นแต่ไม่กล้ากด ไม่เห็น
4.4 ช่อง “ค่าแรงที่คาด” (ปล่อยว่างได้) — ผู้ทดสอบกรอกหรือข้าม
กรอก ข้าม ถามว่าต้องกรอกไหม
ถ้ากรอก — ใส่เลขเท่าไหร่ บาท (เทียบกับค่าแรงงานจริงในระบบ)
4.5 มีช่องไหนที่ผู้ทดสอบลังเลนานที่สุด

5กดสมัครงาน

5.1 ถ้าโปรไฟล์ไม่ครบแล้วกดสมัคร → มีกล่อง “อีก N ขั้นก็สมัครได้เลย” เด้ง — ผู้ทดสอบอ่านแล้วทำตามไหม
กด “กรอกโปรไฟล์” กด “ไว้ทีหลัง” ปิดทิ้ง/งง
5.2 หลังกรอกโปรไฟล์เสร็จ ระบบพากลับมาหน้าหางาน — ผู้ทดสอบรู้ตัวไหมว่ากลับมาที่เดิม
รู้และสมัครต่อ งงว่าอยู่ไหน ไม่ได้กลับมา (บั๊ก)
5.3 สมัครสำเร็จ — ผู้ทดสอบรู้ไหมว่าสมัครไปแล้ว / ต้องรออะไรต่อ
รู้ ไม่แน่ใจว่าสำเร็จไหม ไม่รู้ว่าต้องรออะไร

6ถามหลังจบ (อย่าถามระหว่างทาง)

คำถามคำตอบ (จดคำพูดดิบๆ)
ตรงไหนงงที่สุด
ถ้าให้ใช้เองที่บ้าน จะใช้ต่อไหม เพราะอะไร
แอปนี้เอาไว้ทำอะไร (ทดสอบว่าสื่อสารถูกไหม)
มีตรงไหนที่กลัว/ไม่กล้ากดไหม
ถ้าเพื่อนถามว่าดีไหม จะบอกว่าอะไร

7สรุป — 3 อย่างที่ต้องแก้ที่สุด

เรียงตามความเจ็บที่เห็นกับตา ไม่ใช่ตามที่ผู้ทดสอบบ่น
จุดที่ต้อง “อธิบายให้ฟัง” กี่ครั้งตลอดการทดสอบ ครั้ง
ทุกครั้งที่ต้องอธิบาย = 1 จุดที่ดีไซน์แพ้ · เลขนี้คือคะแนนรวมของแอป ยิ่งน้อยยิ่งดี
