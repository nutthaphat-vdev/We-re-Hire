# 03 — Metrics Tracker (เก็บตัวเลขให้ angel ดู)

> **ไฟล์นี้ใช้ยังไง:** ก็อปตารางข้างล่างไปวางใน Google Sheets แล้วกรอกทุกวัน/ทุกงาน ตัวเลขพวกนี้คือสิ่งที่ angel/VC อยากเห็นตอน pitch ถ้าไม่จด = ไม่มี traction ให้เล่า
> หลักการ: จดตอนเกิดจริง อย่าย้อนเดา · วัด completed + repeat เป็นหลัก ไม่ใช่ signup

---

## ⭐ ตัวเลขที่สำคัญสุดตอน pitch (เรียงลำดับ)

1. **Repeat employer rate** = (employer ที่จ้าง ≥2 ครั้ง) ÷ (employer ทั้งหมด)
   → สำคัญสุด เพราะพิสูจน์ว่า "ไม่ใช่ของเล่นครั้งเดียว" คนกลับมาใช้ = มี value จริง angel ดูตัวนี้ก่อนเพื่อน
2. **Completed jobs** = จำนวนงานที่จบ loop เต็ม (จ่าย/รีวิวแล้ว)
   → ตัวเลข traction หลัก เล่าเป็น "เราทำ X transaction จริง"
3. **Fill rate** = (งานที่มีคนทำจริง) ÷ (งานที่โพสต์)
   → พิสูจน์ว่า marketplace มี liquidity ไม่ใช่โพสต์แล้วเงียบ
4. **GMV** = มูลค่าค่าจ้างรวมที่ไหลผ่านแพลตฟอร์ม
   → ฐานคำนวณ revenue (× 6% = take rate ของเรา)
5. **Week-over-week growth** ของ completed jobs
   → angel ชอบเห็นกราฟชันขึ้น แม้ตัวเลขเล็ก

> สิ่งที่ **ไม่ต้อง** เน้น: ยอด signup, page view, app download — เป็น vanity metric ไม่มี employer/worker คนไหนทำ transaction = ไม่มีความหมาย

---

## 📊 ตาราง 1 — Job Log (กรอกทุกงาน) — ก็อปไป Google Sheets

```
วันที่ | Job ID | ร้าน(Employer) | Worker | ตำแหน่ง | ค่าจ้าง(฿) | Fee 6%(฿) | สถานะสุดท้าย | โซน | หมายเหตุ
```

ตัวอย่างการกรอก:
```
1/7 | J001 | ร้านลุงหมี | สมชาย | ล้างจาน | 450 | 27 | completed | อ่อนนุช | งานแรก! เช็คอินติดนิดหน่อย
1/7 | J002 | ครัวป้านา  | (ไม่มีคน) | เสิร์ฟ | 500 | 0  | unfilled  | อ่อนนุช | worker ในโซนยังน้อย
2/7 | J003 | ร้านลุงหมี | สมหญิง | ครัว  | 480 | 28 | completed | อ่อนนุช | ⭐ repeat ร้านลุงหมี
```

**สถานะที่เป็นไปได้:** posted / hired / checked_in / completed / verified / no_show / unfilled / disputed
> "completed" หรือ "verified" = นับเป็น completed job · "unfilled" = โพสต์แล้วไม่มีคนทำ (กระทบ fill rate)

---

## 📈 ตาราง 2 — Weekly Summary (สรุปทุกสัปดาห์)

```
สัปดาห์ | งานโพสต์ | งาน completed | Fill rate | Employer active | Employer repeat | Worker active | GMV(฿) | Fee รวม(฿)
W1     |          |               |           |                 |                 |               |        |
W2     |          |               |           |                 |                 |               |        |
W3     |          |               |           |                 |                 |               |        |
W4     |          |               |           |                 |                 |               |        |
รวม    |          |               |           |                 |                 |               |        |
```

**สูตร Google Sheets (วางใน summary):**
- Fill rate = `งาน completed / งานโพสต์` → จัดรูปแบบเป็น %
- Repeat rate = `Employer repeat / Employer active` → %
- GMV = `SUM(ค่าจ้าง ของงาน completed)`
- Fee รวม = `GMV * 0.06`

---

## 🧮 ตาราง 3 — Employer Cohort (ดู repeat ชัดๆ)

```
ร้าน | ครั้งที่ 1 | ครั้งที่ 2 | ครั้งที่ 3 | ครั้งที่ 4 | รวมงาน | Repeat?
ร้านลุงหมี | 1/7 | 2/7 | 5/7 | | 3 | ✅
ครัวป้านา  | 3/7 | | | | 1 | ❌
```
> ตารางนี้แหละที่เอาขึ้น pitch deck — เห็น "ร้านเดิมจ้างซ้ำ" ชัดเจน นี่คือหลักฐาน product-market fit ที่ทรงพลังสุดในเฟสนี้

---

## 💡 วิธีบันทึกแบบไม่ขี้เกียจ (สำคัญ)
- เปิด Google Sheets ติดมือถือ ทุกครั้งที่มีงานจบ → กรอก 1 แถวทันที (30 วินาที)
- สิ้นสัปดาห์นั่งสรุป summary 10 นาที
- เก็บ **สกรีนช็อตจาก dashboard backend จริง** ไว้ด้วย (admin/debug endpoint) → ใช้เป็นหลักฐานว่าไม่ได้แต่งตัวเลข
- เก็บ **quote จริง** จาก employer/worker (ขออนุญาตถ่ายแชท/อัดเสียงสั้นๆ) → ใส่ใน one-pager

---

## 🎤 วิธีเล่าตัวเลขตอน pitch (แม้เลขเล็ก)
- ❌ อย่าพูด: "เรามี 20 งาน" (ฟังดูน้อย)
- ✅ พูด: "ใน 30 วัน เริ่มจากศูนย์ เรา validate loop เต็มได้ 20 transaction จริง โดย **40% ของร้านกลับมาจ้างซ้ำ** ทั้งหมดเป็น organic ไม่ได้ยิงแอด ใน 1 โซนเดียว — ถ้าได้ทุนขยายอีก 5 โซน ด้วย playbook เดิม"
- เน้น **อัตรา (rate) + วิธีได้มา (organic, 1 zone)** มากกว่าตัวเลขดิบ → เล่าเป็น "เครื่องจักรที่พิสูจน์แล้ว รอเงินมาเร่ง"
