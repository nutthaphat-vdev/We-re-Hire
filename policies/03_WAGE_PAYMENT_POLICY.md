# นโยบายค่าจ้างและการจ่ายเงิน — WeHire
> ดราฟต์ · ช่วง "ก่อนมีระบบ Escrow" · เวอร์ชัน 1.0 (2026-06-26)
> ใช้คู่กับ ToS ข้อ 3 · ควรแสดงให้ผู้ใช้เห็นชัดตอนโพสต์งาน/รับงาน

## 1. สถานะปัจจุบัน (ยังไม่มีระบบเงินในแอป)
- **WeHire ไม่ถือเงินและไม่เป็นตัวกลางการจ่าย** — Employer จ่ายค่าจ้างให้ Worker **โดยตรง** (เงินสด/โอน)
- WeHire **ไม่รับประกันการจ่ายเงิน** และไม่รับผิดชอบข้อพิพาทเรื่องค่าจ้างที่เกิดนอกระบบ

## 2. แนวปฏิบัติที่แนะนำ (ลดความเสี่ยง)
- ตกลง **อัตราค่าจ้าง + เวลาทำงาน** ให้ชัดเจนในโพสต์งานก่อนเริ่ม
- แนะนำ **จ่ายเมื่อจบงาน (สิ้นสุด shift)** เพื่อให้ช่วงความเสี่ยงสั้นที่สุด
- ยืนยันการจบงานในแอป (complete → verify) เพื่อมีหลักฐาน

## 3. กรณีเบี้ยวค่าจ้าง / ไม่จ่าย
1. Worker กด **"รายงานปัญหา" (report)** ในแอป ระบุงานและรายละเอียด
2. Admin ตรวจสอบหลักฐาน (ประวัติงาน, การเช็คอิน, การสนทนา)
3. ผลการตัดสิน:
   - Employer ที่ผิดจริง → **คำเตือน → ระงับบัญชี → แบนถาวร** ตามความรุนแรง + รีวิวติดลบ
   - กรณีเข้าใจผิด → ไกล่เกลี่ยให้จ่ายให้ครบ
4. WeHire ช่วยเป็นตัวกลางไกล่เกลี่ยและบันทึกประวัติ **แต่ไม่สามารถบังคับจ่ายแทนได้** (จนกว่าจะมี Escrow)

## 4. เครื่องมือป้องกันที่มีในระบบ
- **รีวิว/คะแนน** — Employer/Worker ที่มีประวัติไม่ดีจะถูกหลีกเลี่ยง
- **Behavioral score** — สะท้อนความน่าเชื่อถือจากพฤติกรรมจริง
- **รายงาน + แบน** — กันผู้ใช้ที่มีปัญหาออกจากระบบ
- **KYC** — ลดบัญชีนิรนาม/หลอกลวง

## 5. อนาคต: Escrow (เงินค้ำในระบบ)
- Employer ฝากค่าจ้าง + ค่าบริการเข้าระบบตั้งแต่จ้าง → ปล่อยให้ Worker เมื่อจบงาน
- **การันตีว่า Worker ได้เงินแน่นอน** = แก้ปัญหาเบี้ยวค่าจ้างจากต้นทาง
- ค่าบริการจับคู่ (matching fee) **6% หักจากฝั่ง Worker** (Employer จ่ายเท่าค่าจ้างที่โพสต์) — แสดงเป็นยอดสุทธิที่ Worker ได้รับ
- หาก Worker ทำงานไม่ครบ → คืนเงินตามสัดส่วน (pro-rata) + ค่าปรับตามกติกา
- ระบบนี้ต้องเชื่อมผู้ให้บริการชำระเงินที่ได้รับอนุญาต (เช่น PromptPay ผ่าน PSP) ตามกฎหมายการชำระเงินของไทย
