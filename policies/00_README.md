## วิธีใช้
1. อ่านทุกไฟล์ ปรับให้ตรงกับธุรกิจจริง (ชื่อบริษัท, ที่อยู่, ช่องทางติดต่อ, อายุขั้นต่ำ)
2. ให้ทนายตรวจ (โดยเฉพาะ 02 PDPA)
3. ใส่ลงแอป: หน้า register ต้องมี checkbox "ยอมรับ ToS + Privacy" + consent KYC แยกตอน upload เอกสาร
4. เก็บ timestamp ว่า user ยอมรับเวอร์ชันไหน เมื่อไหร่ (สำคัญตาม PDPA)
