# กฎการใช้งานและความปลอดภัย (Code of Conduct) — WeHire
> ดราฟต์ · เวอร์ชัน 1.0 (2026-06-26) · ปรับ [อายุขั้นต่ำ] ตามประเภทงาน/กฎหมาย

## 1. คุณสมบัติผู้ใช้ (Eligibility) — สำคัญทางกฎหมาย
- **อายุขั้นต่ำ:** Worker ต้องมีอายุไม่ต่ำกว่าที่กฎหมายแรงงานไทยกำหนด (โดยทั่วไป **15 ปีขึ้นไป** และ **ห้ามงานอันตราย/บางประเภทสำหรับผู้เยาว์**) — **ห้ามใช้แรงงานเด็กเด็ดขาด**
- **แรงงานต่างด้าว:** ต้องมี **Passport + Work Permit ที่ถูกต้องและไม่หมดอายุ** จึงจะรับงานได้ (ตรวจผ่าน KYC)
- ผู้ใช้ต้องให้ข้อมูล/เอกสารที่เป็นจริง

## 2. สิ่งที่ห้าม (Prohibited)
- ให้ข้อมูล/เอกสารเท็จ หรือสวมรอยผู้อื่น
- คุกคาม ข่มขู่ เลือกปฏิบัติ หรือล่วงละเมิด
- โพสต์/รับงานที่ผิดกฎหมาย หรืองานอันตรายต่อผู้เยาว์
- ใช้แรงงานเด็ก หรือแรงงานต่างด้าวผิดกฎหมาย
- หลีกเลี่ยงระบบ (เช่น นัดนอกแอปเพื่อหนีค่าธรรมเนียมหลังถูกจับคู่ / bypass)
- ฉ้อโกง เบี้ยวค่าจ้าง หรือไม่มาทำงานโดยไม่แจ้ง (no-show) ซ้ำ
- สร้างรีวิวปลอม/ปั่นคะแนน

## 3. มาตรฐานพฤติกรรม
- ตรงต่อเวลา แจ้งล่วงหน้าหากไปไม่ได้
- สื่อสารสุภาพ ให้เกียรติกัน
- ทำงาน/จ่ายเงินตามที่ตกลง

## 4. การรายงานและบทลงโทษ
- ผู้ใช้รายงานปัญหา/ผู้ใช้รายอื่นได้ผ่านฟังก์ชัน report ในแอป
- Admin ตรวจสอบและดำเนินการตามความรุนแรง:
  1. **คำเตือน (Warning)** — ครั้งแรก/เล็กน้อย
  2. **ระงับชั่วคราว (Suspension)** — ทำซ้ำ/ปานกลาง
  3. **แบนถาวร (Permanent Ban)** — ร้ายแรง เช่น ฉ้อโกง, แรงงานเด็ก, คุกคาม
- กรณีร้ายแรง/ผิดกฎหมาย WeHire อาจดำเนินการทันทีและส่งต่อหน่วยงานที่เกี่ยวข้อง

## 5. ความปลอดภัยในการทำงาน
- WeHire ไม่ได้อยู่หน้างาน ผู้ใช้รับผิดชอบความปลอดภัยของตนเอง
- Worker ควรประเมินความปลอดภัยของงาน/สถานที่ก่อนรับ และปฏิเสธงานที่เสี่ยง/ผิดกฎหมายได้

## 6. การเปลี่ยนแปลง
WeHire อาจปรับกฎนี้และแจ้งในแอป การใช้งานต่อถือว่ายอมรับ
