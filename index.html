How it works
ใช้งานได้ใน 3 ขั้นตอน
👷 สำหรับ Worker
01

สมัครและสร้างโปรไฟล์

ระบุ skills, ที่อยู่, และค่าแรงที่ต้องการ ฟรี 100%

02

ค้นหางานใกล้บ้าน

ระบบ GPS + AI จับคู่งานที่ตรงกับ skills คุณโดยอัตโนมัติ พร้อม match score

03

เช็คอิน GPS → รับค่าแรง

เช็คอินที่หน้างานด้วย GPS ทำงานเสร็จ → verified → รอรับเงิน

🏭 สำหรับ Employer
01

โพสต์งานใน 2 นาที

ระบุตำแหน่ง, skills ที่ต้องการ, ค่าแรง และวันเริ่มงาน

02

03

👷 สำหรับคนหางาน (Worker)
01

สมัครสมาชิก

กด "สมัครสมาชิก" → ใส่เบอร์หรืออีเมล + ตั้งรหัสผ่าน → ติ๊กยอมรับข้อตกลง → กดสมัคร

02

บอกงานที่ทำได้

เลือกทักษะที่ถนัด + ใส่ที่อยู่ + บอกค่าแรงที่ต้องการ (ทำได้เลย ฟรี ไม่มีค่าใช้จ่าย)

03

ยืนยันตัวตน (ทำครั้งเดียว)

ถ่ายรูปบัตรประชาชนหน้า-หลัง + เซลฟี่คู่บัตร → ทีมงานตรวจสอบ → ได้ badge "ยืนยันแล้ว"

04

กด "หางานใกล้ฉัน"

ระบบหางานที่ตรงกับทักษะของคุณในรัศมีใกล้บ้าน → เลื่อนดูงาน → เจองานที่ชอบ กด "สมัคร"

05

รอผลและรับแจ้งเตือน

นายจ้างดูโปรไฟล์ → ถ้าถูกเลือก มีแจ้งเตือนทันที และเห็นเบอร์ติดต่อนายจ้างในแอป

06

เช็คอินวันงาน

ถึงวันงาน ไปที่หน้างาน → กด "เช็คอิน" ในแอป (ต้องอยู่ใกล้จุดงานภายใน 150 เมตร)

07

ทำงานเสร็จ รับเงิน

ทำงานครบ → กด "จบงาน" → รับค่าแรงจากนายจ้างตามที่ตกลงไว้ในโพสต์งาน

🏭 สำหรับผู้จ้าง (Employer)
01

โพสต์งาน

ระบุตำแหน่งงาน ทักษะที่ต้องการ ค่าแรง วันเวลา และที่ตั้ง → กด "โพสต์" ภายใน 2 นาที

02

ดูผู้สมัครและเลือกจ้าง

ระบบคัดและจัดอันดับผู้สมัครให้อัตโนมัติ → เปิดดูโปรไฟล์ → กด "จ้าง" คนที่ใช่

03

ติดตามวันงาน

ได้รับแจ้งเตือนเมื่อ Worker เช็คอิน · ถ้าไม่มา ระบบแจ้งอัตโนมัติและเปิดรายชื่อสำรองทันที

04

ยืนยันจบงาน

Worker กด "จบงาน" → กด "ยืนยัน" เพื่อปิดงาน → ทั้งสองฝ่ายให้คะแนนกัน
